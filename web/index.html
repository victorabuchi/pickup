You don't forget projects. You forget where you were in them.

Connected in about a minute

No per-repository setup. No webhooks. No pasting tokens into forms.

1

Install the agent

A small command-line tool. It runs on your machine and reads your folders — nothing is uploaded yet.

brew install pickup
2

Sign in once

Opens your browser, you approve the device, done. The same flow as the GitHub CLI — no tokens to copy.

pickup login
3

Choose what to sync

It finds your projects and asks which to include. Everything else stays invisible — and you can untrack any project later in one click.

pickup connect ~/Projects
